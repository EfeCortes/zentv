# ZenTV - Zen Dash TV (Museo Políglota)

Dashboard ambiental y relajante optimizado para pantallas tipo Smart TV, monitores secundarios o modo quiosco.

## Características

- **Galería de Arte Clásica:** Obras de alta resolución de Wikimedia Commons (*Van Gogh, Leonardo da Vinci, Hokusai, Vermeer, etc.*) con transiciones suaves en fundido continuo.
- **Reloj y Clima en Vivo:** Hora actual y pronóstico meteorológico para Cochabamba mediante la API de Open-Meteo.
- **Citas y Modelos Mentales Políglotas:** Selección de citas célebres y modelos de pensamiento en 4 idiomas (Español, Inglés, Francés, Alemán).
- **Titulares y Noticias:**
  - Lunes a viernes: Actualidad internacional y nacional (BBC Mundo, CNN Español, Los Tiempos, El Deber).
  - Fines de semana y feriados: Contenido divulgativo y científico (SINC, National Geographic, Yorokobu, Muy Interesante, Xataka).
- **Efemérides:** Detección de festividades globales y feriados de Bolivia.

## Tecnologías

- HTML5 / CSS3 / JavaScript nativo
- Tailwind CSS (CDN)
- Open-Meteo API & RSS2JSON
